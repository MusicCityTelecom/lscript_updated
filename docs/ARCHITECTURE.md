# Architecture

`l` is a small Bash compatibility entry point. `lazy.py` loads `lazytoolkit.cli`.
Runtime code uses Python's standard library and the installed system Bash/Python.

- `core.py`: catalog validation, operating-system detection, executable resolution,
  process invocation and tool state.
- `installers.py`: configured-repository APT packages, per-tool Python virtual
  environments, verified official release assets and bounded archive extraction.
- `bridge.py`, `pentest_patch.py`, `integration.py`: non-destructive integration
  into the existing Bash `pentest-menu`, including argument parsing and rollback.
- `profiles.py`: declarative groups of tools; profiles do not run assessments.
- `workflows.py`: static triage and the existing interactive Metasploit wizard.
- `data/legacy-catalog.json`: original source ledger with aliases/provenance.
- `data/catalog.json`: enriched canonical catalog generated by `tools/build_catalog.py`.
- `legacy/lscript`: original scripts retained as source, not automatically executed.

## Deduplication policy

One canonical ID represents an application. Original labels, source numbering,
categories, repository URLs and command variants remain attached as provenance.
Known aliases such as RED_HAWK/redhawk and RouterSploit/rsf map to the same entry.
JADX's GUI is an action of JADX rather than another installation.

Tools with similar names but different upstream projects are kept separate:
LScript's PowerScript/KatanaFramework is not ProjectDiscovery's Katana crawler.
Likewise, UserRecon is preserved independently of Sherlock; similar purpose alone
is not evidence that two programs are the same tool.

Existing commands resolve first. The application does not recursively guess and
execute arbitrary files from downloaded repositories. Local source entry points
are explicit catalog fields, with a defined interpreter and working directory.

## Boundaries

Catalog inclusion does not imply a current installer, platform support or valid
upstream APIs. Abandoned projects remain visible with an honest state. Old shell
installers are neither sourced nor rewritten into bulk attack automation. User
tool directories are not deleted during application installation or integration.

Release checksums establish agreement with upstream metadata; this project does
not claim to independently audit every downloaded binary or every catalog URL.
No credentials belong in source control.
